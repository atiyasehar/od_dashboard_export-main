OD Dashboard — API User Manual

Read-only JSON REST endpoints for the PopGen OD dashboard server (scripts/run_dashboard.py). Map endpoints may include zone or building shapes as JSON. Test with curl, Insomnia, Postman, Swagger UI, or any HTTP client.

1. Before you call any API

Start the server

.\scripts\start_dashboard.ps1

Leave the terminal open. The server reads PostgreSQL settings from deploy.env.

Base URL

Set one variable in your HTTP client:

VariableExample valuePurpose
base_urlhttp://127.0.0.1:5051Server root — use your deploy.env host/port (default port 5051)

Insomnia

  1. Press Ctrl+E → Manage Environments.
  2. Select Base Environment.
  3. Turn Table View on. Add one row only:
NameTypeValue
base_urlTexthttp://127.0.0.1:5051
  • Type the URL without quote characters.
  • Do not add a second row with Type JSON — that breaks variable resolution.
  • Close the dialog. Select Base Environment in the top-right dropdown.
  • Request URL: {{ base_url }}/api/health

URL preview should show http://127.0.0.1:5051/api/health.

Postman, Bruno, and other clients

{
  "base_url": "http://127.0.0.1:5051"
}

Use {{ base_url }}/api/... in every request below.

curl / PowerShell

Paste the full URL (e.g. http://127.0.0.1:5051/api/health) or set a shell variable.

Add zone and building IDs as query parameters per request — not in the environment.

zone_by and building_by — spell rules or dest

Pass the value exactly in query parameters — lowercase, no spaces:

API value (URL)Dashboard buttonMeaning
rulesRules-basedRouting / meeting rules (default if omitted).
destDestination zoneCounts rolled up to trip destination.

Wrong: Rules-based, destination, Destination zone — use only rules or dest.

?zone_by=rules
?zone_by=dest
?building_by=rules
?building_by=dest

2. Health & reference

GET /api/health

Purpose: Verify server and database. Returns deploy config and zone-label diagnostics.

Parameters: none

Example 1 — smoke test
GET {{ base_url }}/api/health
Invoke-RestMethod "{{ base_url }}/api/health"
Example 2 — check zone labels loaded

Same URL; inspect zone_labels.sample_label_562 and zone_labels.zone_codes_loaded in the JSON body.

Response: "ok": true, "dbname": "od_dashboard", deploy.api_base, zone_labels.

GET /api/montreal_boundary.geojson

Purpose: Montreal island outline (border used to clip or frame the map).

ParameterTypeDefaultDescription
buffer_mfloat—Optional outward buffer (metres)
Example 1 — island outline
GET {{ base_url }}/api/montreal_boundary.geojson
Example 2 — buffered outline
GET {{ base_url }}/api/montreal_boundary.geojson?buffer_m=500
Query parametervalue
buffer_m500

GET /api/od/zone_codes

Purpose: geo_id → zone code and name lookup tables.

Example 1
GET {{ base_url }}/api/od/zone_codes
Example 2 — with environment
GET {{ base_url }}/api/od/zone_codes

Response: zone_codes, zone_names objects keyed by geo_id.

3. Zone maps & boundaries

GET /api/od/zones_boundary

Purpose: Zone polygon outlines. CMM mesh when island_only=0.

ParameterTypeDefaultDescription
island_only0/100 = full CMM mesh; 1 = island clip
Example 1 — full CMM mesh
GET {{ base_url }}/api/od/zones_boundary?island_only=0
Example 2 — island-only
GET {{ base_url }}/api/od/zones_boundary?island_only=1

Response: geojson, zone_count (936), bounds, island_only.

GET /api/od/zone_map

Purpose: Zone map data — per-zone trips, emissions, and distance (colors on the map); optional zone polygon shapes.

ParameterTypeDefaultDescription
zone_byrules | destrulesRules-based or Destination zone
include_geojson0|11Include zone polygon shapes
island_only0|11Island clip
min_kgfloat0Emissions floor (kg CO₂e)
max_kgfloat—Emissions ceiling (kg)
with_building_scale0|10Add legend scale
Example 1 — zone_by=dest (no shapes)
GET {{ base_url }}/api/od/zone_map?zone_by=dest&island_only=1&include_geojson=0&min_kg=0
Paramvalue
zone_bydest
island_only1
include_geojson0
min_kg0
Example 2 — zone_by=rules with shapes
GET {{ base_url }}/api/od/zone_map?zone_by=rules&island_only=1&include_geojson=1&min_kg=0&with_building_scale=1

GET /api/od/zone_maps

Purpose: Both rules-based and destination zone maps in one response.

Example 1 — no geometry (fast)
GET {{ base_url }}/api/od/zone_maps?include_geojson=0&island_only=1
Example 2 — with polygons
GET {{ base_url }}/api/od/zone_maps?include_geojson=1&island_only=1&min_kg=0

Response: dest and rules — each has zone numbers and optional shapes.

GET /api/od/flows_zones

Purpose: Zone metrics for flows map — never returns polygons.

Example 1 — zone_by=dest
GET {{ base_url }}/api/od/flows_zones?zone_by=dest
Example 2 — zone_by=rules
GET {{ base_url }}/api/od/flows_zones?zone_by=rules

4. Zone sidebar (KPIs / charts)

GET /api/od/zone_sidebar

Purpose: KPIs and travel-reason breakdown for one selected zone (sidebar on zone click).

ParameterTypeRequiredDescription
geo_idstringyesZone ID (e.g. 562)
zone_byrules | destnoRules-based or Destination zone (default rules)
dest_geo_idstringnoAlternative name for geo_id
Example 1 — zone_by=rules
GET {{ base_url }}/api/od/zone_sidebar?geo_id=562&zone_by=rules
Example 2 — zone_by=dest
GET {{ base_url }}/api/od/zone_sidebar?geo_id=562&zone_by=dest

Error 400: {"error": "geo_id is required"} if missing.

5. Incoming flows

GET /api/od/zone_incoming_flow

Purpose: Top incoming origins for one destination zone + intra-zone summary.

ParameterTypeRequiredDefaultDescription
dest_geo_idstringyes—Destination zone
zone_byrules | destnorulesRules-based or Destination zone
limitint or allno10Max origin zones
Example 1 — top 10 (default)
GET {{ base_url }}/api/od/zone_incoming_flow?dest_geo_id=562
Example 2 — zone_by=dest, top 25
GET {{ base_url }}/api/od/zone_incoming_flow?dest_geo_id=562&zone_by=dest&limit=25

Response: flows[], dest_zone_trips, intra_zone, dest_lat, dest_lon.

GET /api/od/zone_incoming_flows_all

Purpose: Bulk prefetch — top flows for every destination (heavy).

Example 1 — top 5 per zone (testing)
GET {{ base_url }}/api/od/zone_incoming_flows_all?zone_by=dest&limit=5
Example 2 — zone_by=rules, all origins
GET {{ base_url }}/api/od/zone_incoming_flows_all?zone_by=rules

Response: zones object keyed by dest_geo_id.

6. Buildings

Building endpoints use building_by — spell rules or dest exactly (see above).

GET /api/od/building_emission_scale

Purpose: Min/max building emissions (g) for map legend.

ParameterTypeDefaultDescription
building_byrules | destrulesRules-based or Destination zone
Example 1 — building_by=rules
GET {{ base_url }}/api/od/building_emission_scale?building_by=rules
Example 2 — building_by=dest
GET {{ base_url }}/api/od/building_emission_scale?building_by=dest

GET /api/od/building_map

Purpose: Buildings with emissions inside a zone.

ParameterTypeDefaultDescription
zone_geo_idstring—Required for data
building_byrules | destrulesRules-based or Destination zone
min_kgfloat0Emissions floor (kg)
max_kgfloat—Emissions ceiling (kg)
limitint50000Max rows (100–500000)
island_only0 | 11Island filter
include_footprints0 | 1autoBuilding outline per row
grid_cell_degfloat—Grid cluster size (degrees)
Example 1 — building_by=rules, zone 562
GET {{ base_url }}/api/od/building_map?zone_geo_id=562&building_by=rules&limit=500
Example 2 — building_by=dest, zone 562
GET {{ base_url }}/api/od/building_map?zone_geo_id=562&building_by=dest&min_kg=1&limit=100

GET /api/od/zone_building_fabric

Purpose: All building outline shapes in a zone (grey backgrounds under the colored buildings layer).

Example 1
GET {{ base_url }}/api/od/zone_building_fabric?zone_geo_id=562
Example 2 — limited sample
GET {{ base_url }}/api/od/zone_building_fabric?zone_geo_id=562&limit=200

GET /api/od/building_footprint

Purpose: Single building outline shape by ID.

Example 1

Example 2 — query parameter building_id
GET {{ base_url }}/api/od/building_footprint?building_id=123456

8. Troubleshooting

SymptomCheck
Failed to render environment variables: base_url or bad/illegal formatInsomnia: one Text row only; delete extra JSON rows; select Base Environment
Connection refusedRun start_dashboard.ps1
"ok": false in healthPostgreSQL / deploy.env
503 missing_tableRestore DB dump into od_dashboard (see Dashboard User Manual; dump filename may vary)
Empty zones or flowsTry zone_by=dest if you used rules, or vice versa
Slow / huge responseinclude_geojson=0; add limit
400 geo_id requiredAdd geo_id or dest_geo_id
